Arch Linux Config (Distrobox)

Arch Linux environment configured inside Distrobox. This setup separates development tools from the host system and helps synchronize dotfiles across machines.

Overview

This repo helps you:

Create an Arch Linux environment using Distrobox
Keep the host system clean (no direct dev packages installed)
Manage dotfiles and configuration in one place
Reuse the same setup across multiple machines
Install requirements (Arch Linux)
sudo pacman -S distrobox podman
Clone repository
git clone https://github.com/CapooCapo/archlinuxConfig.git
cd archlinuxConfig
git checkout distrobox
Apply dotfiles

This setup includes:

Pre-configured shell
Synced dotfiles
Prebuilt terminal configuration
Workflow running inside Distrobox container
UI / Setup preview

Terminal & setup
