###Arch Linux Config (Distrobox)

Cấu hình môi trường Arch Linux chạy trong Distrobox, dùng để tách môi trường phát triển khỏi hệ thống chính và đồng bộ dotfiles giữa các máy.

## Tổng quan

Repo này giúp bạn:

Tạo môi trường Arch Linux bằng Distrobox
Giữ hệ thống host sạch, không cài trực tiếp package dev
Quản lý dotfiles và config tập trung
Dùng lại setup trên nhiều máy

Cài nhanh trên Arch:

sudo pacman -S distrobox podman
## Clone repository
git clone https://github.com/CapooCapo/archlinuxConfig.git
cd archlinuxConfig
git checkout distrobox

# Áp dụng dotfiles
Thiết lập môi trường làm việc

Shell được cấu hình sẵn
Dotfiles đồng bộ
Terminal setup theo config cá nhân
Workflow chạy trong container Distrobox
